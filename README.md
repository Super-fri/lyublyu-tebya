# «Люблю тебя» — игра для Android

Это небольшая мобильная игра-кликер, которую можно установить на главный экран Android как приложение. Она оформлена в тёмной сине-серой палитре Telegram, использует приложенные узор, мишку и сердечко. APK здесь нет: приложение устанавливается из браузера, без магазина.

## Как открыть и установить

1. Для быстрого просмотра открой `index.html` в браузере компьютера.
2. Чтобы установить игру на Android, размести содержимое этой папки на HTTPS-сайте. Бесплатный вариант через GitHub Pages:
   - войди на GitHub и нажми **New repository**;
   - назови репозиторий, например `lyublyu-tebya`, и создай его;
   - в репозитории нажми **Add file → Upload files** и перетащи файлы из этой папки (включая папки `assets` и `tools`);
   - нажми **Commit changes**;
   - открой **Settings → Pages**, в источнике выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажми **Save**;
   - дождись публикации ссылки вида `https://твоё-имя.github.io/lyublyu-tebya/`.
3. Открой эту ссылку в Chrome на телефоне. Выбери меню **⋮ → Установить приложение** или **Добавить на главный экран**.
4. После первой загрузки игру можно открывать с новой иконки и играть без сети. Прогресс хранится локально в браузере этого телефона.

Для обычного просмотра интернет не нужен. Он понадобится только для первого размещения и открытия установленной версии. Внешний шрифт подменится системным, если сети нет.

## Что внутри

- `index.html` — разметка экранов и приветственного окошка.
- `styles.css` — цвета, размеры, адаптация под телефон и анимации мишки/сердечек.
- `app.js` — клики, магазин, цены, пассивный доход, приветственный экран и сохранение.
- `manifest.webmanifest` — имя, иконка и режим установки приложения.
- `sw.js` — кэш файлов для запуска без интернета.
- `assets/` — иконка, вырезанный мишка и узор фона.

## Как менять игру самому

Открой папку в редакторе кода, например Visual Studio Code. Чтобы добавить новое усиление:

1. Найди в `app.js` массив `upgrades`.
2. Скопируй один объект и задай ему уникальный `id`, название, описание, значок, начальную цену и коэффициент роста.
3. Добавь его действие в `heartsPerTap()` (сердечки за нажатие) или `heartsPerSecond()` (пассивные сердечки в секунду).
4. Измени `CACHE` в `sw.js` с `v1` на `v2`, чтобы установленные копии получили обновлённые файлы.

Поменять цвета, карточки и анимации можно в `styles.css`. Текст первого сообщения находится в `index.html`. Если захочешь заново получить иконку или вырезать мишку из исходных картинок, на Windows запусти PowerShell из папки проекта и выполни `.\tools\make-assets.ps1`.

### Сохранение

Игра сохраняет сердечки, потраченные сердечки, число нажатий, уровни улучшений и время последнего сохранения в `localStorage` на устройстве. Улучшение «Обнимашки 24/7» продолжает копить сердечки, пока игра закрыта (не более 12 часов за один перерыв). Очистка данных сайта в Chrome удалит и сохранение.

Если хочешь очистить прогресс вручную, открой консоль браузера на странице игры и выполни:

```js
localStorage.removeItem("lyublyu-tebya-save-v1");
location.reload();
```
